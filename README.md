# PFAシミュレーター（ネコムラ・めっけさんとの面談）

発災から約1週間後のマタタビクリニックを舞台に、院長として事務職員「ネコムラ・めっけさん」との面談で返答を7回選びます。選んだ返答に応じて、めっけさんの表情・【様子】・音声が変化します。

- 7場面・22ノード・2,187経路の分岐型ロールプレイです。
- 返答ごとに、◎（PFAの原則に沿った返答）、△（善意や正論でも伝え方や順序を見直したい返答）、✕（PFAの原則に反し訂正が必要な対応）の区分と解説が表示されます。
- 最後に、7場面中の◎の数と、場面ごとの振り返りが表示されます。同じ返答を選べば、何度行っても同じ結果になります。
- 台詞と解説の根拠にした資料は [SOURCES.md](SOURCES.md) にまとめています。

## 構成ファイル

- `index.html`：シミュレーター本体（静的サイトとして動作）
- `scenario.json`：7場面の台本・分岐・評価ルール・UI文言（`build_scenario.py` から生成）
- `audio/`：Gemini 3.8 Flash TTS で合成した全音声と `manifest.json`
- `img/`：Gemini 2.5 Flash Image で生成したキャラクター・場面イラスト
- `build_scenario.py` / `build_audio.py` / `check_audio.py` / `build_images.py`：生成と検証用スクリプト

## デモ経路（URLパラメータ）

- `?demo=good`：7場面すべて◎で良い結末へ進む経路
- `?demo=earlysolve`：場面2で早すぎる解決指示を選び、場面3で立て直す経路
- `?demo=neutral`：関係は保てるが具体的な支援につながらない経路
- `?demo=harmful`：PFAの禁止事項（✕）を含む経路
- `?demo=poor`：緊張と不信が高まる経路
